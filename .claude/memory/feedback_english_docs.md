Documentation must always be in English. This applies to README, docs/, code comments, commit messages, and PR descriptions.

**Why:** User preference for consistency and accessibility.

**How to apply:**
- README.md: English
- docs/*.md: English
- Code comments: English
- strings.json: Danish (user-facing UI strings in Home Assistant)
- This aligns with the CLAUDE.md convention: "English for code, Danish for user-facing strings"
