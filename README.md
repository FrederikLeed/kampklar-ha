# KampKlar for Home Assistant

[![HACS Custom](https://img.shields.io/badge/HACS-Custom-41BDF5.svg)](https://hacs.xyz/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

> **Work in Progress** — Denne integration er under aktiv udvikling og er ikke klar til brug endnu.

Home Assistant custom integration for [DBU KampKlar](https://klubservice.dbu.dk/kampklar/) — aktivitetsstyring for danske fodboldklubber.

## Planlagte features

- **Sensorer**: Naeste kamp/aktivitet, tilmeldingsstatus, holdtilgaengelighed
- **Kalender**: Alle holdaktiviteter som HA calendar entity
- **Service calls**: Tilmeld/afmeld aktiviteter direkte fra HA
- **Dashboard**: Eksempel Lovelace dashboards og automations
